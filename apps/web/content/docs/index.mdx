Mtoast is an opinionated toast component for React. You can read more about why and how it was built [here](https://blog.mosespace/ui/building-a-toast-component).

## Installation
Install the package from your command line.

<Tabs items={['pnpm', 'npm', 'yarn', 'bun']}>
  <Tab>```pnpm add @mosespace/toast```</Tab>
  <Tab>```npm install @mosespace/toast```</Tab>
  <Tab>```yarn add @mosespace/toast```</Tab>
  <Tab>```bun add @mosespace/toast```</Tab>
</Tabs>

No Tailwind setup is required. Styles are bundled inside the package and injected automatically when `Toaster` renders.

### Add Toaster to your app

It can be placed anywhere, even in server components such as `layout.tsx`.

```tsx
import { Toaster } from '@mosespace/toast';

export default function RootLayout({
  children,
}: {
  children: React.ReactNode;
}) {
  return (
    <html lang="en">
      <body>
        {children}
        <Toaster position="bottom-right" />
      </body>
    </html>
  );
}
```

### Simple Usage

```tsx
import { toast } from '@mosespace/toast';

function MyToast() {
  return (
    <button
      onClick={() =>
        toast.success('Rendered!', 'This is a smooth mtoast notification.')
      }
    >
      Render my toast
    </button>
  );
}
```
